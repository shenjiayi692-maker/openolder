live_set (Ableton Live 12 to 11 conversion)

The Ableton Live 12 to 11 conversion rules in /lib/als.js are ported from live_set by Michael Slinn, used for noncommercial purposes under the Live Set Tools Noncommercial License 1.0 below.

Significant modifications: ported from Ruby to JavaScript with a small formatting-preserving XML tree so it runs in the browser; only the Live 12 to Live 11 direction is implemented; the source version is detected by the "12." version prefix; an inspection report (tempo, tracks, plug-ins, Live 12-only content) was added.
