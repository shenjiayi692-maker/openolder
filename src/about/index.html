About OpenOlder

OpenOlder is a small independent project made by Jiayi, an independent developer based in Canada. It exists because editors and producers often receive project files saved in a newer version of their software than the one they have, and updating isn't always possible: a studio may be locked to one version, or a client's machine may not support the new release.

How it works

A Premiere Pro project (.prproj) is compressed XML. OpenOlder opens it in your browser, adds back the fields older versions expect, sets the version number and gives you a new copy. Ableton Live sets (.als) are handled the same way. Everything runs on your own computer: your files are never uploaded, there is no account, and the original file is not changed.

What it can and can't do

  • Premiere Pro: converts projects and Productions from 2026 back to older versions. Features that only exist in the newer release may show as missing.
  • Ableton Live: converts Live 12 sets for Live 11 (beta). Devices that only exist in Live 12 can't be recreated.
  • It doesn't convert media, render files or plug-ins, only the project file.

Always keep the original and check the converted project before relying on it.

Privacy

Your project files are processed in your browser and never uploaded. To find out whether the tools work for people, the pages send an anonymous count when something happens, for example "a project was converted to Premiere Pro 2025" or "a file could not be read" (for a file that cannot be read, also its extension, what kind of file its first bytes show, for example gzip or zip, and a size range). Only daily totals are stored: the event, the page and a short category such as the target version. No file names, project contents, IP addresses or cookies are recorded, and the counts cannot be linked to you.

Credits and independence

The Premiere conversion is based on prem-down by Luis Gómez Gutiérrez (MIT) and the Ableton conversion on live_set by Michael Slinn (noncommercial license). Details are on the licenses page. OpenOlder is not affiliated with or endorsed by Adobe or Ableton.

Open source

The Premiere Pro conversion code is also available as an open-source library and command-line tool: prproj-downgrade (MIT, based on prem-down).
